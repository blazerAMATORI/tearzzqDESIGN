# funpay/tearzzq — витрина оформлений

Статический сайт-каталог для продажи оформлений Steam-профиля. Пользователи листают
и открывают в полный экран, ты — добавляешь новые витрины руками (см. ниже).

## Структура

```
index.html          — главная страница (шапка + каталог + лайтбокс)
admin.html          — локальный помощник для добавления новых оформлений
css/style.css       — стили
js/main.js          — рендер каталога и логика лайтбокса
js/admin.js         — логика admin.html
data/designs.json   — список оформлений (редактируешь вручную)
images/             — сами картинки
```

## Как посмотреть локально

Открыть `index.html` двойным кликом не сработает как надо (браузер блокирует
загрузку `data/designs.json` с диска). Нужен локальный сервер, это одна команда:

```
cd tearzzq-site
python3 -m http.server 8000
```

Затем открой `http://localhost:8000` в браузере.

## Как добавить новое оформление

Сайт статический — базы данных и «кнопки загрузки» для всех посетителей тут
нет и не нужно (её как раз и не должно быть, чтобы никто чужой ничего не
загрузил). Загружаешь контент только ты, и делаешь это так:

1. Открой `admin.html` локально (тем же `python3 -m http.server`).
2. Укажи номер, название, выбери файл картинки.
3. Скачай файл с готовым именем (`design-03.png` и т.д.) и положи в папку `images/`.
4. Скопируй сгенерированный JSON-блок и вставь его внутрь массива в `data/designs.json`.
5. Сохрани, закоммить и запушь — сайт обновится сам.

Можно и без admin.html — просто добавь файл в `images/` и допиши объект в
`data/designs.json` вручную:

```json
{
  "id": 3,
  "title": "Название",
  "image": "images/design-03.png",
  "note": "необязательное описание"
}
```

## Как залить на GitHub Pages

```
cd tearzzq-site
git init
git add .
git commit -m "первая версия сайта"
git branch -M main
git remote add origin https://github.com/<твой-ник>/<репозиторий>.git
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Source: Deploy from a branch →
branch: main / (root)**. Через минуту сайт будет доступен на
`https://<твой-ник>.github.io/<репозиторий>/`.

## Про кнопку «Выбрать это оформление»

FunPay не поддерживает ссылки с заранее заполненным текстом сообщения в
чате — такого параметра в URL у них нет. Поэтому кнопка:

1. копирует в буфер обмена готовое сообщение вида
   `Здравствуйте! Выбрал оформление №03 («Название»)...`;
2. открывает твой профиль FunPay в новой вкладке.

Покупателю останется нажать «Написать» и вставить (Ctrl+V) уже готовый текст.
Если у FunPay в будущем появится поддержка префилла через URL — скажи, поправлю.

## Логотип и стиль

Лого `funpay/tearzzq` в углу — отсылка к расположению названия на баннере
YouTube. Кольцо вокруг аватарки и туманный готический скайлайн в шапке —
привет вайбу референсов (туман, силуэт шпилей, синее свечение). Меняется в
`css/style.css`, переменные цвета — в самом верху файла (`:root`).

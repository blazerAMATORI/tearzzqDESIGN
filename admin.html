Опубликовать оформление

Заполняешь форму — жмёшь «Опубликовать» — картинка и запись в каталоге сами уходят в репозиторий на GitHub. Сайт обновится через 10–30 секунд, руками ничего заливать не нужно.

1. Подключение к GitHub

Нужен персональный токен с доступом только к этому репозиторию. Делается один раз:

Открой github.com/settings/personal-access-tokens/new → Repository access: Only select repositories → выбери свой репозиторий → Permissions → Contents: Read and write → Generate token → скопируй его (показывается один раз).
